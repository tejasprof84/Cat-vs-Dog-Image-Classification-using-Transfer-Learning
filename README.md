# Cat vs Dog Image Classification using Transfer Learning

A deep learning system that identifies whether an uploaded image contains a **cat or a dog**. The project uses **transfer learning** and compares three popular CNN architectures: **MobileNetV2**, **EfficientNetB0**, and **ResNet50**, integrated into a **Streamlit** web application with ensemble majority voting.

---

## Models

| Model | Description | Highlights |
|---|---|---|
| **MobileNetV2** | Lightweight & fast | Suitable for quick predictions |
| **EfficientNetB0** | Balanced efficiency | Highest accuracy – **97.4%** |
| **ResNet50** | Deep & robust | Residual connections for strong feature learning |

---

## Project Structure

```
├── app.py           # Streamlit web application
├── train.py         # Model training script
├── requirements.txt # Python dependencies
├── models/          # Saved model files (generated by train.py)
└── data/            # Training data (not included – see below)
    ├── train/
    │   ├── cats/
    │   └── dogs/
    └── validation/
        ├── cats/
        └── dogs/
```

## Setup

```bash
pip install -r requirements.txt
```

---

## Training the Models

1. Prepare your dataset in the `data/` directory with the structure shown above (e.g. the [Kaggle Cats vs Dogs dataset](https://www.kaggle.com/c/dogs-vs-cats/data)).
2. Run the training script:

```bash
python train.py
```

This trains all three models and saves them to `models/`.

---

## Running the Web App

```bash
streamlit run app.py
```

Open the URL shown in the terminal (usually `http://localhost:8501`).

### How it works

1. Upload a JPG/PNG/WEBP image using the file uploader.
2. Click the **Predict** button.
3. The app runs inference with all three models and displays:
   - Predicted class (**Cat** or **Dog**) per model
   - Confidence score per model
4. A **majority voting** mechanism combines the three predictions to produce a final answer.
